# Your Neura workspace

1. Install or select Neura on the host where this folder lives.
2. Create a project or open a `.nra` source file.
3. Use Run, Build, and Debug in the editor toolbar.
4. Open Testing to discover exported `test_` functions.
5. Choose a Neura color theme if you want the website's pink/blue palette.

Windows users should reopen the folder in Remote WSL before installing the Linux toolchain. Restricted Mode keeps syntax and themes available; trust the workspace before executing tools.
